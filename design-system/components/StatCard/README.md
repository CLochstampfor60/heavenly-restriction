# StatCard

One headline number with a label and a short qualifier, in a row of two or three.

**Classes:** `hr-stat` with an `hr-eyebrow` label, `hr-stat__value` and `hr-stat__sub`.

- The value uses tabular figures. The qualifier may take a signal color only when it means that signal (`flash` for a PR, `accent` for an improvement).
- Pair with `hr-meter` when the number is progress toward a target.
