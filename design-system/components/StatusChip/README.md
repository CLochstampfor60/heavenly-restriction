# StatusChip

How each exercise ended, so the day summary is honest: Done, Skipped, Swapped or Stopped.

**Classes:** `hr-chip` plus `hr-chip--done`, `hr-chip--swapped` or `hr-chip--stopped` (Skipped is the base chip).

**The consumer provides:** the status and, for Swapped, the exercise actually done (shown next to the chip, e.g. "Swapped → Cable row").

- Icon plus word every time; the four are told apart without color.
- Not tappable. If a chip needs an action, put a button beside it.
