# GradeBadge

Shows an exercise's progression level using the spreadsheet's grades: Grade 4, 3, 2, 1, then Special Grade.

**Classes:** `hr-grade`, and `hr-grade--sm` inside dense rows.

**The consumer provides:** the grade name, and nearby in `text-2` the plain version ("Level 3 of 5") and what the next grade needs.

- `grade` on `grade-soft`. Gold appears only on progress and library screens, never beside a Stop button.
- The grade name is the JJK term, so always pair it with the plain level line somewhere on the same row.
