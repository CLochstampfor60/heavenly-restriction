# RegionTag

Names the body region and muscle an exercise trains, in the library's grouping (Region › Muscle).

**Class:** `hr-tag`.

**The consumer provides:** the region and muscle names from the exercise's `muscle_group`.

- Always `cursed` on `cursed-soft`, for every region. Regions are told apart by their words, so there is no per-region color palette.
- Not tappable. 24 px tall.
